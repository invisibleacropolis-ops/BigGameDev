# Original Brief


i want to come up with a brainstorm session here with you about a game i want to make.  i have a lot of ideas but they need to be tied together and also fleshed out


so the basic idea is similar to combining a lot of other games.. the general gameplay is akin to Battlezone where the player is controlling a vehicle or character, along with controlling squadrons of other vehicles and AI assistants... any of them can be controlled by the player remotely, either through SWAT style commands of "follow" or "attack here" or "guard this"... or directly by summing full FPS control of the unit


then the other world based layer would be a combination of things like xcom and midwinter and magic carpet and civilization and HOMM and so on- along with unique aspects... for example i want the base building and all other world level interactions to be controlled by "playing cards" whereby the player has a certain hand of cards per tern to interact with the world at this level... this is where ideas need most fleshed out - but generally things like "build structure" or "locate resources" or"produce heavy assault units" or "worker revolt" or "airstrike" and so on running the entire range and then some, along with all kinds of modifiers and alts and so on...


and importantly this card logic needs to be real - in the sense that the player is compteing against opponents using the same cards to interact with the world, and therefor this level of the game itself has an entirely different kind of AI involved, and yet it still needs to direct and control the AI ground units effectively and contextually to the overall strategy - so there are many layers to consider here.  How to start with a simple set of cards and actions, then ramp it up in a traditional deckbuilding style of more and more options.


so the world view would be a real time 3d view, along with the typical top down military style UI interface, but layered over the view of real 3d space with all the objects and interactions, etc,, and the Player is typically tasked with some kind of World Objective like "conquer all territories" or "harvest 1000+ metal" or some other massive overarching goal - and we need great variety here.  The Player will be competing against AI which will typically have most if not all the same available resources and goals and objectives as the player - akin to magic carpet or civilization, etc.  They will also have the same "armies" of units available.


the interface level here can be planned out in all kinds of detail - its almost like a RTS style interface - so that we can see all the units moving about - select different ones and give different orders, direct them in different ways and so on.. assign to groups and squads, put them in formations, do rally points... guard patrols, etc and so on - all the things you want from the RTS control



in terms of Buildings we can inspect all kinds of things and get all kinds of supporting information and views and see all kinds of relationships from resources to buildings to units... but again the actual "playing" or manipulating the world in terms of BUILDING entirely controlled by card interactions since ultimately the player agency is more about the real time layer - and controlling units, piloting them, doing objectives, etc


  but the cards should probably each consume a certain amount of time and/or have instant effects.. so that if all cards have been played, they still may be active etc.. so the world view also progresses through a day and night cycle, and each full day would be a certain number of Turns so a certain number of Cards can be played.  


In addition, each Turn also has a certain number of Random World Events... spawned through a system of logic of some sort, so that the "randomness" always has a legitimate context to the current map scenario and situation 


These Events would also span a range of things from something like "Sattelite crash site" or "Earthquake mine shaft" or "Cityscape located" etc and so on, which will provide an additional layer of essential "Mission based gameplay" loop which is tied back into the standard base building and map conquest


because i want to add a number of layers of procedural detail for world events.  ultimately the goal is to create a vast wealth of gameplay from various interactions of players in various events happening emergently - for example a random mission for "Return generator part to cyborg base" has a timer on it, and the generator part can be captured from enemy players - therefore they will  hunt and pursue and/or race each other to the goal.  and so various other kinds of mission types can be generated which leverage this kind of logic in various ways


the Player bases would be typical of other RTS or 4X games where you have various buildings doing various real world functions like unit production or ambient benefits, along with upgradeable levels and expansion grids for land etc..  it would require various kinds of resources on the world map found with various kinds of tech in various levels of rarity..


and the idea of "Cards" adds to a loot based mechanic where they can be found or earned in the game world... which adds as much uniqueness and rarity as we want, where we can create a vast library of rare items to be found or fought over, etc


the kinds of units available will also cover a wide range but the key here is on fun physics.. mostly sim based but leaning morw towards conematic action when necessary...  the key motion style is "hover based" so there wont be wheels or or treads, etc, just hovercars hovertrucks hovertanks, along with true jets and flying vehicles... and player characters that can move in a fps style like Tribes - with jetpacks and skiing - so that vehicle and player movement has a continuum of sameness... and the physics engine itself can remain coherent and tweaked for maximum fun in this kind of movement style


the art direction will be unique.. all 3d model and landscape textures will be 256 color - based on the same pallette.. and the overall resolution of polygons and geometry and texture size will be of the Playstation 1 era - so quite lofi... however other kinds of modern shaders and particle fx and so on will be used, and may use the entire color spectrum.


what we need to do is come up with a design bible that contains all our thoughts and ideas and concept art and diagrams and so on, and also has the ability to grow continuously with our design... so for now we can just put everything into an obsidian folder here.. with supporting images and md docs linked through hyperlinks and so on
